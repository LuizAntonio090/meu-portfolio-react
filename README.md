# Portfólio React — Luiz Corrêa

Projeto desenvolvido com React + Vite.

## Requisitos
- Node.js (versão LTS recomendada)
- npm

## Executar localmente
1. Extraia o ZIP.
2. Abra a pasta `portfolio-react` no VS Code.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra no navegador o endereço local mostrado no terminal (normalmente http://localhost:5173).

## Gerar versão de produção
```bash
npm run build
```
Os arquivos finais serão gerados na pasta `dist`.

## Publicar no GitHub e na Vercel
1. Crie um repositório no GitHub e envie os arquivos deste projeto.
2. Entre na Vercel e importe o repositório.
3. A Vercel identifica o Vite automaticamente.
4. Use `npm run build` como comando de build e `dist` como diretório de saída, se solicitado.
5. Após o deploy, copie o endereço público e envie na atividade.

## Personalizações importantes antes de entregar
- Em `src/App.jsx`, troque `SEU_EMAIL_AQUI` pelo seu e-mail no link `mailto:`.
- Substitua o link genérico do LinkedIn pelo seu perfil pessoal.
- Revise os textos de habilidades, cursos e projetos para refletirem exatamente sua experiência.
- Se possível, adicione links para os repositórios dos outros projetos.
